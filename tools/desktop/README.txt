Last Ink
========

Windows: run LastInk.exe. Windows may say it "protected your PC" because the game is not signed
yet: click "More info", then "Run anyway".

macOS: open the zip, drag "Last Ink.app" to Applications, then right-click it and choose Open the
first time (the game is not notarised by Apple yet). If macOS still refuses, open System Settings >
Privacy & Security and click "Open Anyway".

Linux: run ./LastInk.x86_64. To add it to your app menu, run ./install-desktop-entry.sh once.

Saves and settings
  Windows  %APPDATA%\Last Ink
  macOS    ~/Library/Application Support/Last Ink
  Linux    ~/.local/share/Last Ink
Options > Save folder opens it. The logs folder there helps with bug reports.

Keys: Alt+Enter or F11 switches between windowed and fullscreen. Options > Display has the
window mode, size, scaling, vsync, a frame cap and what happens when the window loses focus.
